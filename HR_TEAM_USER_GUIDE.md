# Catalysts Recruitment Screening Skill
## HR Team User Guide

### Official Master Repository

https://github.com/manojcatalysts/recruitmentscreening.git

The GitHub repository is the official master version of the Skill.

---

## First-Time Installation

1. Open ChatGPT.
2. Go to Skills.
3. Open Skill Installer.
4. Select Try now.
5. Provide the official GitHub repository:
   https://github.com/manojcatalysts/recruitmentscreening.git
6. Install the skill:
   catalysts-recruitment-screening
7. Confirm that Catalysts Recruitment Screening appears under Personal → Installed.

---

## Updating the Skill

When HR announces a new version:

1. Open Skill Installer.
2. Select Try now.
3. Ask it to update the existing:
   catalysts-recruitment-screening
4. Provide the official repository:
   https://github.com/manojcatalysts/recruitmentscreening.git
5. Tell the installer:
   "Replace the existing installation with the latest repository version. Do not create a duplicate Skill."
6. Confirm the update.

---

## Important Rules

- Do not create a second Catalysts Recruitment Screening Skill.
- Do not modify the Skill independently.
- Always use the official GitHub repository.
- Candidate CVs and SDS reports must not be uploaded to GitHub.
- Candidate information should remain within the appropriate private ChatGPT conversation/workspace.
- Use one dedicated recruitment conversation per hiring requirement.
